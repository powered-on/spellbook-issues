# Spellbook — Bug Reports & Feature Requests

Public issue tracker for [Spellbook](https://spell-book.uk), an unofficial fan companion for tabletop World of Darkness games.

**This repository is for feedback only.** It does not contain application source code, and pull requests are not accepted here. Development happens in a private repository maintained by Powered On Productions.

## What is Spellbook?

Spellbook is a private, Discord-gated companion for trusted tables. It helps players and storytellers manage characters, powers, and live play across multiple game systems.

Spellbook is **not affiliated with, endorsed by, or sponsored by** Paradox Interactive, White Wolf, or any other rights holder. World of Darkness and related marks belong to their respective owners.

## Current features

- **Discord sign-in** — OAuth with player/admin allowlists, optional open enrollment, and user bans
- **Characters** — searchable character roster, system-specific sheets, active character pin, safe delete, GM assignment
- **Spells / Powers** — free-form Effects with pluggable requirements, assignment, JSON export/import with duplicate resolution
- **Play Mode** — two-column active character sheet with assigned Effects and mismatch indicators
- **Table Mode** — shared table view with co-player visibility controls
- **GM Mode** — named games, character moves, read-only multi-character scan
- **Multi-system support** — Mage: the Ascension (M20), Vampire: the Masquerade (V20), Werewolf: the Apocalypse (W5), and more
- **System config** — enable/disable game systems and adjust presentation options per system

## Report a bug

1. Go to [**Issues**](https://github.com/powered-on/spellbook-issues/issues).
2. Click **New issue**.
3. Choose **Bug report** and fill in the template.

Please include:

- Steps to reproduce
- Expected vs actual behavior
- Browser/device (if relevant)
- Which Spellbook page or mode (Characters, Play Mode, GM Mode, etc.)
- Screenshots when helpful

## Request a feature

1. Go to [**Issues**](https://github.com/powered-on/spellbook-issues/issues).
2. Click **New issue**.
3. Choose **Feature request** and describe the problem you are trying to solve.

## What not to post

Please **do not** include in public issues:

- Passwords, session tokens, or Discord OAuth secrets
- Private table data, character names, or player-identifying information you do not have permission to share
- Exploit details without a brief responsible-disclosure note (contact maintainers first for security-sensitive findings)

## Accessing Spellbook

Spellbook is invite-gated. If you already have access, open [https://spell-book.uk](https://spell-book.uk).

If you need access, contact your storyteller or table admin — not this issue tracker.

## Triage

Issues are reviewed by maintainers and labeled as needed (`bug`, `enhancement`, `needs-triage`, etc.). Confirmed bugs may be tracked internally in the private development repository.
